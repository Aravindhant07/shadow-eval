Method and gates
  • Correct answer: when agent and team agree, their shared decision; when they disagree, the expert's verdict (agent wrong / team wrong / both acceptable / both wrong with the correct decision). Unreviewed disagreements assume the team was right.
  • Matching: {% for f in sc.domain.decision %}{{ f.name }} {% if f.match == 'tolerance' %}within {{ (f.tolerance_pct*100)|round(1) }}% or {{ f.tolerance_abs | num }}{% else %}{{ f.match }}{% endif %}{% if not loop.last %}; {% endif %}{% endfor %}.
  • GO gate: accuracy lower 95% bound ≥ {{ sc.domain.readiness.min_accuracy | pct(0) }}, critical rate ≤ {{ sc.domain.readiness.max_critical_rate | pct }}, cost ≤ {{ sc.domain.readiness.max_cost_per_100 | num }} per 100, at least {{ sc.domain.readiness.min_cases }} cases.
  • Guardrail: lowest confidence threshold where the auto-handled slice passes the GO gate and covers ≥ {{ sc.domain.readiness.min_guardrail_coverage | pct(0) }} of cases.
  • Spot checks: {{ sc.domain.readiness.spot_check_rate | pct(0) }} of agreements are sent to experts to estimate shared mistakes.
  • Audit: every case, decision and review is recorded in a hash-chained log; shadow verify-audit detects any edit or deletion.
